## Findings

1. **High - README quick start does not install pytest** (`README.md:34`)

   The new setup flow tells fresh users to run `uv sync --dev` before `uv run pytest`, but this project defines its test tooling under `[project.optional-dependencies].dev` in `backend/pyproject.toml`, not as a uv dependency group. With uv 0.8.22, `uv sync --dev --dry-run --offline` resolves only the base 28 packages and does not include `pytest`, `pytest-asyncio`, `pytest-cov`, or `ruff`; `uv sync --extra dev --dry-run --offline` resolves those dev tools. As written, the documented fresh-checkout path leaves the next command without pytest available.

   Suggested fix: change the install command to `uv sync --extra dev`, or move the dev tools to a `[dependency-groups]` `dev` group if `uv sync --dev` is the intended workflow.
